# Seed-команды backend

## Системные упражнения

Запускать из папки `backend`:

```bash
python -m app.seeds.system_exercises
```

Что делает команда:
- добавляет недостающие системные упражнения;
- обновляет поля существующих системных упражнений;
- не создает дубликаты при повторном запуске (idempotent).

## Справочник (категории и статьи)

Запускать из папки `backend`:

```bash
python -m app.seeds.system_guide
```

Что делает команда:
- добавляет недостающие категории (по `name`) и статьи (по паре «категория + `title`»);
- обновляет описание/позицию/время чтения существующих записей;
- иконки и inline-медиа грузятся в bucket только при первой вставке записи (чтобы не плодить сирот в S3);
- не создает дубликаты при повторном запуске (idempotent); `views_count` не трогается.

Ассеты (иконки категорий/статей и медиа для текста) кладутся в `app/seeds/assets/guide/`.
В тексте статьи (`content`) используются плейсхолдеры `{{media:имя_файла}}` — при сидировании
файл грузится в bucket, а плейсхолдер заменяется на стабильную ссылку `/api/guide/media/{object_key}`.
