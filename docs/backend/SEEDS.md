# Seed-команды backend

## Системные упражнения

Запускать из папки `backend`:

```bash
python -m app.seeds.system_exercises
```

Что делает команда:
- добавляет недостающие системные упражнения;
- обновляет поля существующих системных упражнений;
- грузит фото/видео упражнения в bucket и привязывает их строками `exercise_media`;
- не создает дубликаты при повторном запуске (idempotent).

Медиа упражнений (фото/видео, можно несколько) кладутся в `app/seeds/assets/exercises/`,
а имена файлов указываются в поле `media_filenames` у `SystemExerciseSeed`. Медиа грузится
при первой вставке упражнения, а также догружается для уже существующих упражнений, у которых
медиа ещё нет; если медиа уже привязано — повторно не заливается и не дублируется.
Порядок файлов в `media_filenames` задаёт порядок медиа (`position`) в карточке упражнения.

Пример упражнения с медиа:

```python
SystemExerciseSeed(
    name="Жим штанги лёжа",
    description="Базовое упражнение для развития массы и силы грудных мышц...",
    primary_muscle_groups=["chest"],
    secondary_muscles=["chest", "triceps", "deltoids"],
    equipment=["Штанга", "Скамья"],
    media_filenames=["bench-press.jpg", "bench-press.mp4"],
)
```

## Справочник (категории и статьи)

Запускать из папки `backend`:

```bash
python -m app.seeds.system_guide
```

Что делает команда:
- добавляет недостающие категории (по `name`) и статьи (по паре «категория + `title`»);
- обновляет описание/позицию/время чтения существующих записей;
- иконки и inline-медиа грузятся в bucket только при первой вставке записи (чтобы не плодить сирот в S3);
- не создает дубликаты при повторном запуске (idempotent); `views_count` не трогается.

Ассеты (иконки категорий/статей и медиа для текста) кладутся в `app/seeds/assets/guide/`.
В тексте статьи (`content`) используются плейсхолдеры `{{media:имя_файла}}` — при сидировании
файл грузится в bucket, а плейсхолдер заменяется на стабильную ссылку `/api/guide/media/{object_key}`.

## Системные шаблоны тренировок

Запускать из папки `backend` (после `system_exercises`, т.к. шаблоны ссылаются на упражнения по имени):

```bash
python -m app.seeds.system_workout_templates
```

Что делает команда:
- добавляет недостающие системные шаблоны (по `title`, `created_by_user_id IS NULL`);
- обновляет описание и список упражнений существующих системных шаблонов;
- упражнения в `SystemTemplateSeed.exercise_names` адресуются по имени системного упражнения;
  отсутствующие в БД упражнения пропускаются с предупреждением `[warn]`;
- не создает дубликаты при повторном запуске (idempotent).

Шаблон хранит только упорядоченный список упражнений (без подходов/повторений/веса).
