# Seed-команды backend

## Системные упражнения

Запускать из папки `backend`:

```bash
python -m app.seeds.system_exercises
```

Что делает команда:
- добавляет недостающие системные упражнения;
- обновляет поля существующих системных упражнений;
- не создает дубликаты при повторном запуске (idempotent).
